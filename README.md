# RESTful API

A RESTful API built with Node.js and Express.

## About The Project

An Express application exposing REST endpoints (see `api/routes/countries.js`) with an MVC structure (`mvc/`: controllers, routes and EJS views), backed by MongoDB through Mongoose. The repository includes a `Procfile` (Heroku deployment) and a `docker-compose.yml`.

## Built With

- Node.js / Express
- MongoDB (Mongoose)
- EJS

## Getting Started

Install the dependencies with `npm install`, then start the server with `npm start` (runs `node ./bin/www`). A MongoDB connection is required.
